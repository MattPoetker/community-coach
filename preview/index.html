Four directions

A direction owns layout, component anatomy and the information model — it ships as code. A theme owns colour, type and spacing — it is data an owner edits. Kiln, Hearth and Grove are three themes of one direction. The three below are different directions: different structures, not different paint. Every one of them still reads the same brand tokens, so every one is still whitelabel.

Kiln
Default
App shell. Sidebar, card feed, right rail. The format members already know from every other community product. Safe, legible, unsurprising — and the reason it is the default.
App Landing
Broadsheet
Writing-led
A publication. No cards at all. Masthead, 12-column asymmetric grid, lead story with a drop cap, briefs, letters, a pull quote. Hierarchy comes from column width and position, so the host's announcement can actually outrank a reply — which a uniform feed can never express.
Open
Console
Operators
A queue. Fixed split pane, one-line rows, a filter query instead of categories, a persistent detail pane instead of navigation, and a status bar of keyboard shortcuts. Nothing scrolls infinitely. You work it to zero and leave.
Open
Studio
Media-led
A broadcast. Full-bleed hero for the next live call, then horizontal rails rather than a vertical feed — five categories in one screen instead of one category five times. Discussion is demoted to a rail, because for these cohorts it is genuinely the secondary product.
